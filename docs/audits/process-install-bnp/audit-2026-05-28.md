- **Les autres systèmes IA BNP** vs Twin. AI Act art. 49 demande un inventaire — pas accessible ici.

### 11.2 — Ce qui est sourceable mais incomplet

- Les memories sont datées de 2026-05-XX (rappels système : 6-17 jours d'âge). Elles sont fiables sur la **doctrine** mais peuvent être périmées sur des éléments **opérationnels**.
- Le `changelog.md` documente bien les versions techniques (v0.3.2 → v1.0.0) mais pas une seule entrée ne mentionne "déployé en BNP le X par Y" — confirme l'absence d'audit trail formel.
- `CLAUDE.md` couvre l'architecture du package + git workflow + CI, mais zéro mention d'un process Install BNP. **Trou principal du repo.**

### 11.3 — Biais potentiels

- **Biais Julien-centré.** Les sources mémoire sont celles de Julien. Les meetings sont sa lecture des réunions. Les contre-arguments BNP (côté Fabrice, Salah, Louis) sont rapportés par Julien — pas vus directement.
- **Biais "tout va bien".** Le projet a reçu 4 validations seniors consécutives (Manu, Fabrice, Salah, Geoffrey — cf. `project_geoffrey_meeting_2026-05-28.md`). Ça peut créer un faux sentiment de robustesse compliance. Louis 2026-05-28 a explicitement cassé ce sentiment (*« YOLO partout »*). Cet audit assume Louis a raison.
- **Biais d'omission documentaire.** Si BNP a déjà un process Install qui couvre Twin (CAB, runbook, etc.) **mais que Julien ne l'a pas reçu/lu**, cet audit le signalera comme inexistant à tort. À vérifier lundi en posant explicitement la question.

### 11.4 — Ce que cet audit n'est PAS

- **Ce n'est pas un audit de code.** Le code lui-même est couvert par les Prismes A-G existants (`docs/audits/lightrag-1.4.9.11/`).
- **Ce n'est pas un audit financier ou contractuel.** Pas d'avis sur le coût du projet ni sur les modalités contractuelles.
- **Ce n'est pas un blame.** Le SPOF Julien est assumé côté Julien (cf. directive globale). L'audit constate le gap structurel **vis-à-vis du régulateur**, pas vis-à-vis de Julien personnellement.
- **Ce n'est pas une feuille de route prescriptive.** Les recommandations §9 sont des candidats — c'est à Julien + Fabrice de les arbitrer.
