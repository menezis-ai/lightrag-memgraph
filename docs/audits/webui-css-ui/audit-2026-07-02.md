# WebUI CSS/UI Audit Baseline - 2026-07-02

## Scope

This audit covers the Twin WebUI fork under `lightrag_webui_twin/`, with focus
on CSS architecture, visual resources, token consistency, component duplication,
and short-term harmonization work. It is code-level first: no backend behavior
or API contract is audited here.

## Immediate Harmonization Applied

- `src/styles/tokens.css` is now the canonical home for global design variables:
  maquette primitives, semantic aliases, fonts, radii, shadows, status colors,
  toast timings, and light/dark values.
- `src/styles/app.css` no longer redefines the legacy token block at the top or
  the maquette token bridge in the middle of the file.
- CSS variable scan after the change: `77` variables defined, `75` variables
  used, `0` used variables missing a definition.
- `app.css` dropped from `12109` to `11936` lines. This is not a full cleanup,
  but it removes the most damaging token duplication without changing the
  effective maquette palette.

## Harmonization Doctrine

- `tokens.css` owns all global variables. No new `:root` token bridges in
  `app.css`.
- Component CSS may consume semantic tokens (`--color-*`, `--twin-*`) or local
  component variables scoped under the component selector.
- New fixed visual values should be classes, not inline `style`, unless they are
  truly data-driven.
- One component family should have one source of truth: do not keep an embedded
  implementation and an extracted implementation active in parallel.
- Keep the maquette palette as the upper target for now. Reverting to the older
  flat blue/white legacy tokens would be a visual downgrade.

## Proposed Cleanup Order

1. Topbar: wire extracted `FolderSwitcher`, `TodoBell`, and
   `SystemStatusIndicator` or delete them if intentionally abandoned; then
   collapse `.topbar*`, `.tabs`, `.folder-pill`, `.ws-*`, `.notif-*` CSS.
2. Documents shell: consolidate `.docs-header`, `.docs-header-actions`,
   `.docs-filters`, `.search-source`, `.docs-row.has-select`, and mobile rules.
3. Modal system: replace per-component inline widths with classes such as
   `.modal-sm`, `.modal-md`, `.modal-lg`, `.modal-xl`.
4. Graph panel: separate data-driven graph colors from fixed inspector layout;
   move the many inspector margin/font inline styles into CSS.
5. Resource cleanup: decide fate of `public/icons.svg`; keep fonts and
   `Icon.tsx` as the deliberate resource stack unless the whole app moves to an
   icon package.

## Residual Risk

The token move is low-risk because it preserves the effective maquette values
that `app.css` was already applying later in the cascade. The larger risk is the
remaining cascade stack: future UI fixes can still regress unrelated screens
until duplicated selectors are consolidated by domain.

## Cleanup Pass 1 - 2026-07-02

- `Topbar.tsx` now uses the extracted `Topbar/FolderSwitcher.tsx`; the private
  duplicated `FolderMenu` implementation was removed.

  tests: `Escape` closes the menu, the trigger keeps the `Switch folder` title,
